Вступ

CSS (Cascading Style Sheets) дозволяє створювати гарні веб-сторінки, але як він працює "під капотом"?
У цій статті пояснюється, що таке CSS, як виглядає його базовий синтаксис і як браузер застосовує CSS до HTML для стилізації.

Попередні вимоги:

  • Базові знання роботи з файлами
  • Знання HTML

Чого ви навчитеся:

  • Зрозумієте призначення CSS.
  • Дізнаєтесь, що HTML не відповідає за стилізацію.
  • Розберетеся в концепції стилів браузера за замовчуванням.
  • Ознайомитеся з основами CSS-синтаксису.
  • Дізнаєтесь, як CSS застосовується до HTML.

Стилі браузера за замовчуванням

У попередньому модулі ми розглянули, що таке HTML і як він використовується для розмітки документів.
Ці документи будуть читатися у веб-браузері.
Заголовки виглядають більшими, ніж звичайний текст, абзаци переходять на новий рядок і мають пробіл між ними, посилання підкреслені та мають інший колір для відмінності від основного тексту.

Те, що ви бачите, — це стилі браузера за замовчуванням.
Вони являють собою базову стилізацію, яку браузер застосовує до HTML, щоб сторінка залишалася читабельною навіть без явного вказання стилів автором.
Ці стилі визначені у стандартних CSS-таблицях стилів браузера і не мають відношення до самого HTML.

Для чого потрібен CSS?

Використовуючи CSS, ви можете повністю контролювати зовнішній вигляд HTML-елементів у браузері, представляючи документи користувачам у будь-якому дизайні та макеті.

Документ — це, як правило, текстовий файл, структурований за допомогою мови розмітки, найчастіше HTML. Проте можна зустріти документи на інших мовах розмітки, таких як SVG та XML.
HTML-документ містить контент веб-сторінки та визначає його структуру.

Представлення документа користувачеві означає перетворення його у форму, зручну для сприйняття. Браузери (Firefox, Chrome, Safari, Edge) призначені для візуального представлення документів на екрані комп’ютера, мобільного пристрою, проектора або принтера. У веб-контексті цей процес називається рендерингом.

Примітка: Браузер іноді називають "користувацьким агентом" (user agent), що означає комп'ютерну програму, яка представляє користувача в системі.

CSS дозволяє:
Стилізувати текст (наприклад, змінювати колір і розмір заголовків і посилань).
Визначати макет сторінки (наприклад, розташовувати текст і зображення в стовпцях і рядках).
Створювати анімацію (наприклад, змінювати колір кнопки при наведенні курсору).

CSS організований у модулі, що містять відповідний функціонал. Наприклад, модуль Backgrounds and Borders відповідає за фони та рамки елементів.

Основи синтаксису CSS

CSS — це мова на основі правил. Ви визначаєте правила, вказуючи групи стилів, які слід застосовувати до певних елементів HTML на вашій веб-сторінці.

Наприклад, якщо ви хочете зробити заголовок <h1> великим і червоним, використовуйте такий код:

         
h1 {
    color: red;
    font-size: 2.5em;
   }

Приклади стилів у CSS

Приклади стилів у CSS
CSS-код Опис Результат
h1 { color: red; } Робить заголовок червоним Червоний заголовок
p { font-size: 18px; } Збільшує розмір тексту в <p>. Текст 18px
div { background: blue; color: white; } Синій фон, білий текст. Білий текст на синьому фоні

Примітка: Якщо вам потрібно дізнатися більше про якусь властивість, шукайте її в довідниках MDN, w3schools.

Як CSS застосовується до HTML?

Коли ви відкриваєте веб-сторінку, браузер спочатку отримує HTML-документ з контентом сторінки та перетворює його у DOM-дерево.

Потім він знаходить усі CSS-правила (як вбудовані в HTML, так і у зовнішніх .css файлах) і групує їх залежно від елементів, до яких вони застосовуються.
Після цього CSS-правила накладаються на DOM-дерево, створюючи рендер-дерево, яке потім відображається у вікні браузера.

Приклад HTML-коду:

            
<h1>CSS — це круто</h1>
<p>Ви можете стилізувати текст.</p>
<p>А також створювати макети та спецефекти.</p>
CSS-код:
h1 {
  color: red;
  font-size: 2.5em;
}
p {
  color: aqua;
  padding: 5px;
  background: midnightblue;
}
